# Portfolio de Alba Pareja

Portfolio personal de diseño gráfico y web, desarrollado con HTML y CSS. La web presenta los principales ámbitos de trabajo de Alba Pareja y permite navegar entre las páginas de proyectos y su perfil profesional.

## Contenido

- **Inicio:** presentación personal, servicios, habilidades y contacto.
- **Branding:** información sobre proyectos de identidad de marca.
- **Diseño web:** apartado dedicado a proyectos web y experiencias digitales.
- **Diseño editorial:** sección de proyectos de diseño editorial.
- **Artefinalización:** sección de trabajos relacionados con la preparación de archivos y arte final.
- **Sobre mí:** trayectoria, experiencia y perfil profesional.

## Tecnologías

- HTML5
- CSS3
- Google Fonts
- SVG
